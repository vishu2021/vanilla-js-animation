# 🎨 Vanilla JS Animation Components
A collection of **modern UI components and interactive animations** built using **pure HTML, CSS, and JavaScript (Vanilla JS)**.
This repository focuses on lightweight, performant, and reusable UI patterns without relying on any external frameworks.
---
![Vanilla JS Animation](https://blog.logrocket.com/wp-content/uploads/2020/04/comparing-js-animation-libraries.jpeg)
---
## 🚀 Features
- ⚡ 100% Vanilla JavaScript (No frameworks)
- 🎨 Modern UI components
- 🧩 Reusable and modular code
- 📱 Responsive design
- 🎬 Smooth animations & transitions
- 🧠 Real-world UI patterns
---
## 🛠 Tech Stack
- 🌐 HTML5  
- 🎨 CSS3 (Animations & Transitions)  
- ⚙️ JavaScript (ES6+)
